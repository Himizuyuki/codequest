# Useful links and where to look things up

Bookmark these - looking things up fast is a real interview and job skill.

## Reference
- **cppreference** - the C++ reference. Search it for any function or type: https://en.cppreference.com/w/
  - Containers: https://en.cppreference.com/w/cpp/container
  - Algorithms (`<algorithm>`): https://en.cppreference.com/w/cpp/algorithm
  - Strings: https://en.cppreference.com/w/cpp/string
  - Utilities (`optional`, `variant`, `pair`, ...): https://en.cppreference.com/w/cpp/utility
- **C++ Core Guidelines** - what "good C++" means: https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines
- **isocpp FAQ**: https://isocpp.org/wiki/faq

## Learning
- **learncpp.com** - free, thorough, beginner to advanced: https://www.learncpp.com/
- **hacking C++** - visual cheat sheets for containers and algorithms: https://hackingcpp.com/
- **Compiler Explorer** - see assembly and try snippets in a browser: https://godbolt.org/
- **CppCon talks** on YouTube: https://www.youtube.com/@CppCon

## Practice and interviews
- **NeetCode roadmap** - the classic patterns in a sensible order: https://neetcode.io/roadmap
- **LeetCode**: https://leetcode.com/
- **Big-O cheat sheet**: https://www.bigocheatsheet.com/

## Books
- *A Tour of C++* (Stroustrup) - the fast overview of modern C++.
- *Effective Modern C++* (Meyers) - the "why" behind C++11/14 idioms.
- *Cracking the Coding Interview* (McDowell) - the interview classic.
